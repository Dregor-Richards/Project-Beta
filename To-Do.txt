Install Flask or FlashAPI

To get ready in your venv, you’d install either:

FastAPI + Uvicorn:

bash
pip install "fastapi[standard]" uvicorn
FastAPI docs explicitly recommend installing with the extras like that.

Or Flask:

bash
pip install Flask
(Ideally inside a virtualenv, which you’re already comfortable with.)

Then you’ll expose a small /api/generate-level endpoint that takes difficulty 
and returns JSON.
